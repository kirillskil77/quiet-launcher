# 🚀 [quite-launcher]

Минималистичный, быстрый и удобный лаунчер для Minecraft, созданный на чистом вайбе. Ничего лишнего — только игра.

## ✨ Особенности

* **Поддержка разных версий операционной системы windows** – поддерживаются такие версии системы Windows как: Windows 7,Windows 10,Windows 11.
* **поддержка различных аккаунтов** — поддержка таких аккаунтов как: оффлайн , а так же "ely.by"
* **Шустрый запуск** — стартует моментально без тяжеловесных анимаций.
* **Простой интерфейс** — интуитивно понятный дизайн, в котором разберется каждый.
* **Управление версиями** — [ поддержка Vanilla/Forge/Fabric или автоматическая загрузка].
* **Легковесность** — не расходует лишние ресурсы ПК в фоновом режиме.
