# 🚀 Quiet-launcher

Минималистичный, быстрый и удобный лаунчер для Minecraft, созданный на чистом вайбе. Ничего лишнего — только игра.

## ✨ Особенности

* **🖥️ Поддержка разных версий ОС** — стабильно работает на Windows 7, Windows 10 и Windows 11.
* **🔌 Поддержка различных аккаунтов** — можно играть в Offline-режиме (оффлайн), а также использовать альтернативную систему скинов и авторизации Ely.by.
* **⚡ Шустрый запуск** — стартует моментально без тяжеловесных анимаций.
* **🧼 Простой интерфейс** — интуитивно понятный дизайн, в котором разберется каждый.
* **📦 Управление версиями** — поддержка ванильных версий (Vanilla), а также модифицированных платформ Forge и Fabric.
* **🍃 Легковесность** — не расходует лишние ресурсы ПК в фоновом режиме.

## 🛠️ Технологии

Проект написан с использованием:
* Python

## 🚀 Как запустить: Готовый релиз

1. Перейдите в раздел **Releases** на панели справа.
2. Скачайте файл **"Quiet-launcher setup.exe"** .
3. Распакуйте скачанный архив в удобное место.
4. Найдите в папке и запустите файл `Quiet-launcher setup.exe`.
5. Наслаждайтесь игрой! 😊
