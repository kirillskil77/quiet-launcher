# Quiet Launcher

Сдержанный лаунчер для Minecraft: Java Edition. Один exe-файл, без установки, работает на Windows 7 SP1 и новее.

- **Сборки** — у каждой своя папка с игрой, модами, сохранениями и настройками (память, Java, аргументы JVM). Можно создавать, дублировать, удалять, импортировать из `.mrpack`.
- **Каталог** — вкладка «Каталог»: моды, ресурс-паки, шейдеры и готовые сборки с Modrinth. Стрелка у названия открывает страницу проекта (описание и скриншоты), двойной клик ставит сразу. Моды ставятся с обязательными зависимостями. Вкладка «Установлено» — обновление, удаление, свои `.jar`. Загрузчики: Fabric, Quilt, Forge (в том числе старые, до 1.12.2), NeoForge.
- **Обновления** — при запуске лаунчер раз в несколько часов смотрит последний релиз на GitHub; если он новее, появляется кнопка «Обновить» (сборки и миры остаются). Отключается в «Настройках».
- **Приветствие** — один раз для каждой версии: что нового и кто делал.
- **Вход** — офлайн-ник («пиратка»), Ely.by (с двухфакторной защитой и скинами через authlib-injector), Microsoft (вход по коду).
- **Java** — по умолчанию берётся Java от Mojang, как в официальном лаунчере (скачивается сама). Если она не скачалась или не запускается на этой системе, лаунчер ставит Java Zulu 21. Путь к Java можно не указывать (подбор автоматический) или нажать «Найти…»: лаунчер покажет все Java на компьютере, в том числе из других лаунчеров, и даст выбрать.

- **Журнал** — кнопка «Журнал» сверху открывает `data/launcher.log`; ошибки установки Forge/NeoForge показывают последние строки установщика.
- **Вид** — скруглённый интерфейс, мягкий зелёный фон с медленно плывущими пятнами (как в лава-лампе) и плавные наведения/переключения. Анимации можно выключить в «Настройках» («Анимированный фон») или переменной `QL_NO_ANIM=1`; во время игры и при свёрнутом окне они сами останавливаются.
- **Плавность** — по умолчанию запускает игру с параметрами JVM как в официальном лаунчере (сборщик мусора G1 с короткими паузами, куча сразу полного размера). Отключается в «Настройках»; свой сборщик мусора в аргументах JVM лаунчер не перебивает.

## Установка (для друзей)

Запустите `QuietLauncher-Setup.exe`: он ставит лаунчер в профиль пользователя (права администратора не нужны), создаёт ярлыки и удаляется через «Программы и компоненты». Сборки и миры лежат в папке `data` рядом с программой и при удалении по умолчанию остаются.

## Запуск из исходников

Нужен Python 3.8 (на нём работает Windows 7). Больше ничего, кроме `certifi` (корневые сертификаты — на Windows 7 системные часто устарели):

```
py -3.8 -m pip install -r requirements.txt
py -3.8 main.py
```

или двойной клик по `run.bat`.

## Сборка установщика

Нужны Python 3.8 и [Inno Setup 6](https://jrsoftware.org/isdl.php). Двойной клик по `build.bat` → `dist\QuietLauncher-Setup.exe` (его и отправляйте друзьям) и `dist\QuietLauncher\` (то же без установки, как portable-папка). Если Inno Setup не стоит, скрипт соберёт только папку с программой. Нет Windows под рукой — запустите workflow «Build installer» в GitHub Actions (`.github/workflows/build.yml`).

## Публикация версии и обновления

Адрес репозитория для обновлений задан в `ql/endpoints.py` (`GITHUB_REPO`, по умолчанию `kirillskil77/quiet-launcher`). Репозиторий должен быть **публичным**.

1. Поднимите номер в `ql/__init__.py` (`APP_VERSION`), запустите `build.bat` → `dist\QuietLauncher-Setup.exe`.
2. На GitHub: *Releases* → *Draft a new release* → тег `v1.3.1` (с буквой v и тем же номером) → прикрепите `QuietLauncher-Setup.exe` → *Publish release*. В описание напишите, что нового: его покажет окно обновления.
3. У пользователей на следующем запуске появится кнопка «Обновить».

Либо отправьте тег (`git tag v1.3.1 && git push --tags`): workflow «Build installer» сам соберёт установщик и создаст релиз.

## Оформление, пресеты, копии миров (1.4)

- **Настройки → Оформление:** четыре темы (чёрная по умолчанию, графит, тёмно-синяя, тёмно-фиолетовая), цвет акцента
  (готовые или свой), три раскладки окна: классика, зеркальная, компактная. Раскладка применяется сразу,
  тема и акцент — после перезапуска (палитра задаётся при старте, `ql/theme.py`).
- **Настройки → Производительность:** пресеты JVM «По умолчанию» (как было), «Баланс», «Максимум FPS», «Слабый ПК».
  Свой сборщик мусора в аргументах JVM пресеты не заменяют. Выигрыш зависит от компьютера и сборки — это не волшебная кнопка.
- **Голова у ника:** для Ely.by и Microsoft скачивается скин (`skinsystem.ely.by`, `sessionserver.mojang.com`) и вырезается лицо,
  для офлайна рисуется стандартная голова. Нужна Pillow.
- **Иконки сборок:** блоки и лица мобов вырезаются из клиентского jar на компьютере игрока (`ql/icons.py`) и лежат в `data/cache/icons`.
  Файлы Mojang в лаунчер не входят. Иконки появляются после первого запуска любой сборки.
- **Копии миров:** `ql/backup.py`. Перед запуском, в фоне, только если мир изменился; последние N копий (по умолчанию 3) в
  `<сборка>/backups/<мир>/*.zip`; мир больше 2 ГБ или мало места — пропуск с записью в журнал. Восстановление создаёт
  новую папку мира рядом со старым, ничего не перезаписывая. Для Forge 1.5.2, который хранит игру в `%APPDATA%\.minecraft`,
  копии не делаются.
- **Окно после обновления:** `ql/changelog.py` (списки по поколениям `GENERATIONS`, мелкие правки по версиям `PATCHES`).
  При выпуске 1.4.1 добавьте пункты в `PATCHES["1.4.1"]`, при 1.5.0 — новое поколение в `GENERATIONS["1.5"]`.

## Друзья (1.4.1)

Вкладка «Друзья»: добавление по коду (`QL-XXXXXX`), заявки с подтверждением, блокировка. Список ваших проектов Modrinth
и статус «в лаунчере / играет» видны друзьям, только если вы включили переключатели (по умолчанию выключены). Друг видит
названия и id проектов, но не файлы; установка идёт из каталога Modrinth. Сервер — бесплатный Cloudflare Worker, описание
и развёртывание в `server/README.md`. Если сервер недоступен, лаунчер и игра работают как обычно.

## Вход через Microsoft

Лаунчеру нужен свой **client id** приложения Azure (чужой подставлять нельзя):

1. portal.azure.com → *Microsoft Entra ID* → *App registrations* → *New registration*.
2. Тип аккаунтов: *Personal Microsoft accounts only* (или вариант «любые каталоги + личные»).
3. *Authentication* → *Allow public client flows* = **Yes**.
4. Скопируйте *Application (client) ID* и вставьте в Настройки или в окно входа Microsoft.
5. Minecraft Services принимает только одобренные приложения: пока Mojang не одобрит ваш client id, вход заканчивается ошибкой «Invalid app registration». Заявка подаётся по форме на https://aka.ms/AppRegInfo (порядок может меняться — проверяйте актуальные правила).

Дальше вход идёт по коду: лаунчер откроет страницу и покажет код, вводите его, подтверждаете вход. Нужна купленная Minecraft: Java Edition.

## Вход через Ely.by

Ник или e-mail и пароль от Ely.by. Если включена двухфакторная защита, лаунчер запросит код. Для запуска автоматически скачивается `authlib-injector`.

## Windows 7: что важно знать

- Нужен Service Pack 1 и обновление KB2999226 (Universal C Runtime) — без него лаунчер не запустится.
- Официально Java 21 Windows 7 не поддерживает, но на практике Java от Mojang часто запускается (проверено на 1.21.x). Если нет, лаунчер после проверки сам скачивает Zulu 21 (около 50 МБ с серверов Azul — иногда медленно). Это можно отключить в «Настройках».
- Если ничего не помогло, укажите свою Java («Найти…» в настройках).

```
main.py          вход
installer/       скрипт установщика (Inno Setup)

ql/auth.py       офлайн, Ely.by, Microsoft
ql/game.py       версии, библиотеки, ресурсы, команда запуска
ql/javart.py     Java: Zulu 21, рантайм Mojang, автопоиск
ql/loaders.py    Fabric / Quilt / Forge / NeoForge

ql/updater.py    обновление лаунчера через GitHub Releases
ql/changelog.py  текст приветственного окна
ql/instances.py  сборки
```

## macOS (Apple Silicon) и Linux — первые сборки

- macOS: `QuietLauncher-macOS-arm64.zip` → внутри `QuietLauncher.app`. Подписи Apple Developer нет, поэтому при первом запуске:
  правый клик по приложению → «Открыть» (или `xattr -dr com.apple.quarantine QuietLauncher.app`).
- Linux: `QuietLauncher-linux-x86_64.tar.gz`, внутри папка `QuietLauncher`, запуск `./QuietLauncher`. Нужен системный Tk не требуется (он внутри сборки).
- Данные: macOS — `~/Library/Application Support/QuietLauncher`, Linux — `~/.local/share/QuietLauncher`.
- Игра на M1: полноценно работает с Minecraft 1.19+ (там есть нативные библиотеки LWJGL под arm64). Для 1.13–1.18 и старее нужна замена LWJGL или Java под Rosetta — в планах.
- Автообновление на macOS/Linux пока только уведомляет и открывает страницу релиза.
